INDEPENDENT SOFTWARE PROJECT / FINTECH

FastConvert

FastConvert was an independent software project for converting cryptocurrency values to Kenyan shillings. I worked with market data, multiple cryptocurrencies and an investment simulator.

Problem
Checking a cryptocurrency’s value in KSh can mean manually working through exchange rates.
What I built
A cryptocurrency-to-KSh converter with live market data and an investment simulation.
My role
Independent project: frontend, backend, API integration, error handling and deployment.
Tools
JavaScript, Python, Flask and cryptocurrency APIs.
What it taught me
Practical experience with APIs, conversion logic, data handling and responsive application development.

Cari Studio
